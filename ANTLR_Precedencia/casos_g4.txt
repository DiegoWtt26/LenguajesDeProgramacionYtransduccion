# casos_g4.txt — G4 PrecFlat: SIN niveles (todo a la izquierda, sin precedencia)
# Un solo nivel que se pliega siempre por la izquierda (diapo 30 por ausencia):
#   expr : atom (op atom)*     (evaluacion estrictamente de izquierda a derecha)
#   atom : NUM | '(' expr ')'
# Uso:  python3 main.py casos_g4.txt
# Nota: main.py corre las 4 para comparar, pero ESTE archivo solo documenta G4.
# Lo que hay que ver aqui (diapos 29-30):
#  - NO hay niveles: 2+3*4 da 20 igual que G3 pero POR OTRA CAUSA (pliegue plano).
#  - El caso estrella 2*3+4*5 da 50: distinto de G1 (=26) Y de G3 (=70).
#  - La cadena larga 2+3*4-5/5 da 3 (ni 13 de G1 ni -1 de G3).
#  - El parentesis SI manda (es lo unico que rompe el pliegue plano).
2 + 3 * 4
# => 20  (((2+3)*4) pliegue de izquierda a derecha, sin niveles)
10 - 2 * 3
# => 24  (((10-2)*3) pliegue plano)
2 * 3 + 4 * 5
# => 50  ((((2*3)+4)*5): CASO ESTRELLA, distinto de G1 y de G3)
2 + 3 * 4 - 5 / 5
# => 3  (pliegue plano completo de izquierda a derecha)
7 / 2 + 1
# => 4.5  (((7/2)+1) pliegue plano con division real)
(2 + 3) * 4
# => 20  (el parentesis manda, como en todas)
42
# => 42  (un solo operando: no hay pliegue que mostrar)
2 + * 3
# => RECHAZADA (sintaxis invalida: falta operando)
