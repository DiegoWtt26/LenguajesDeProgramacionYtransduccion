# casos_g2.txt — G2 PrecRight: DERECHA + precedencia CORRECTA (*/ > +-)
# Misma precedencia que G1, pero recursion al reves (diapo 28: E -> T op E):
#   e : t ('+'|'-') e | t      (asociatividad derecha)
#   t : f ('*'|'/') t | f      (asociatividad derecha)
#   f : NUM | '(' e ')'
# Uso:  python3 main.py casos_g2.txt
# Nota: main.py corre las 4 para comparar, pero ESTE archivo solo documenta G2.
# Lo que hay que ver aqui (diapos 27-28):
#  - Los operadores del MISMO nivel agrupan a la DERECHA.
#  - Si NO se repite operador del mismo nivel, coincide con G1 (misma precedencia).
#  - El caso largo 100/10/2+1 muestra la derecha dentro de la cadena de /
#    (100/(10/2)=20) con el + fuera por precedencia (+1 al final).
4 - 3 - 2
# => 3  (4-(3-2), derecha, diapo 28)
8 / 4 / 2
# => 4  (8/(4/2), derecha)
10 - 2 + 3
# => 5  (10-(2+3): el + de la derecha agrupa primero)
100 / 10 / 2 + 1
# => 21  (((100/(10/2))+1): la / agrupa a la derecha y el + queda fuera por precedencia)
2 + 3 * 4
# => 14  (2+(3*4): sin repetir operador del nivel, igual que G1)
2 * (3 + 4)
# => 14  (el parentesis manda, como en todas)
7
# => 7  (un solo operando: mismo arbol en cualquier asociatividad)
2 + * 3
# => RECHAZADA (sintaxis invalida: falta operando)
